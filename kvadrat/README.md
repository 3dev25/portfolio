# Квадрат

Кабинет агентства недвижимости: карточки объектов и статусы.

## Стек
React 18, Vite, Node.js, Express, PostgreSQL

## Локальный запуск
Импортируйте `database/schema.sql` в PostgreSQL; установите зависимости `npm install`; задайте `DATABASE_URL`; запустите API `npm run server` и интерфейс `npm run dev`. API: GET/POST `/api/properties`, PATCH/DELETE `/api/properties/:id`.

## Важно
Это портфолио-демо. Перед production-развёртыванием добавьте аутентификацию и авторизацию, CSRF-защиту для PHP-форм, rate limiting, валидацию и журналирование. Не открывайте операции изменения и удаления публично без проверки прав. Используйте секреты только в переменных окружения, не коммитьте пароли.

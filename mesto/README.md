# Место

Сайт ресторана с демонстрационной формой бронирования.

## Стек
PHP 8+, MySQL 8+, JavaScript

## Локальный запуск
Настройте DB_HOST, DB_NAME, DB_USER, DB_PASSWORD, импортируйте `database/schema.sql`, запустите PHP 8+ с PDO MySQL. API формы: `POST api/lead.php`; таблица `reservations`.

## Важно
Это портфолио-демо. Перед production-развёртыванием добавьте аутентификацию и авторизацию, CSRF-защиту для PHP-форм, rate limiting, валидацию и журналирование. Не открывайте операции изменения и удаления публично без проверки прав. Используйте секреты только в переменных окружения, не коммитьте пароли.

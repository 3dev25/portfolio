# 3dev25 Portfolio

Коллекция из восьми адаптивных демонстрационных веб-проектов для российского малого бизнеса и SaaS.

Каждый проект находится в отдельной папке. PHP-проекты содержат SQL-схему и интерактивный интерфейс; React-проекты содержат клиентское приложение и Node.js API.

## Проекты

- `sever-stroy/` — корпоративный сайт строительной компании.
- `forma-dent/` — сайт стоматологической клиники.
- `mesto/` — сайт ресторана с меню и формой бронирования.
- `nord-home/` — каталог мебели с фильтрами и корзиной.
- `orbit-crm/` — CRM с задачами и сделками.
- `smena/` — SaaS-планировщик смен.
- `kvadrat/` — кабинет агентства недвижимости.
- `pravo/` — сайт юридической компании.

Все данные в демо-интерфейсах являются демонстрационными. Перед production-развёртыванием необходимо подключить реальные учётные записи, БД, почту и платёжные сервисы.
